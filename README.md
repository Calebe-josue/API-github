# Projeto que consome a API REST do github
Projeto desenvolvido em Python que consome uma **API REST do GitHub** utilizando a biblioteca **request**.

A aplicação permite listar todos os eventos realizados por um usuário do GitHub em um determinado período.

Este projeto foi desenvolvido com foco em compreender como uma API REST funciona, como ocorre a comunicação cliente-servidor, O que a API retorna (Estrutura de dados JSON), organização de código e bocas práticas básicas em Python, modularização e **Arquitetura MVC** como preparação para o padrão **MVT** do Django.


# Objetivo do projeto
Praticas e consolidar conhecimentos em:
- Estrutura de um projeto Python
- Arquitetura MVC e entendimento do padrão MVT
- Manipulação de arquivos JSON
- Consumo de APIs REST
- Leitura e interpretação de documentação de API
- Identificação de endpoints
- Lógica de programação


# Funcionalidades
- Listar eventos do perfil do GitHub


# Tecnologias utilizadas
-   Python 3
-   JSON
-   Terminal
-   Módulo **time**
-   Módulo **Request**
-   API REST Do GitHub
