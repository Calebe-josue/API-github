# Projeto que consome a API REST do github
Projeto em Python que consome uma **API REST do GitHub** utilizando a biblioteca **request**.

Permite Listar todos os eventos que o usuário fez em um determinado periodo.

Este projeto foi desenvolvido com foco em entender como uma API REST funciona, como ela se comunica no sistema e oque ela retorna, organização de código e bocas práticas básicas em Python, modularização e **Arquitetura MVC** para se preparar para o **MVT** do Django.
